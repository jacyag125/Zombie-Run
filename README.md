# Zombie Run

## Game Overview

Zombie Run is a fast-paced survival game where the goal is to stay alive for 20 seconds while avoiding zombies.

## Rules

- You control a character trying to survive.
- Zombies are deadly — if the character touches a zombie, the game ends.
- Survive for 20 seconds to win.
- If you do not touch the zombies, you remain safe.

## Objective

Stay alive. Avoid the zombies. Survive the full 20 seconds.

## How to Play

1. Move the character around the game area.
2. Keep distance from zombies.
3. Do not touch any zombie.
4. Reach the 20-second countdown without collision.

## Win Condition

- Win by surviving the full 20 seconds without touching a zombie.

## Lose Condition

- Lose immediately if the character touches a zombie.

## Tip

- Stay alert and keep moving — the safest path is one that never touches the zombies.
